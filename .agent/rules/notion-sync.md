# Notion DB 동기화 규칙 (rules/notion-sync.md)

1. **사전 조건**:
   - `rules/notepad-prep.md`에 따라 마크다운 사전 정리가 완료된 데이터만 Notion에 동기화 등록합니다.

2. **단편 문학 등록 프로세스**:
   - 단편 글 -> 해당 카테고리/명예의 전당 Notion DB 항목으로 등록 (게시물 제목, 링크, 태그, 사진 정보).

3. **시리즈 문학 등록 프로세스 (예시 '빛을 따라서' 구조 규정)**:
   - 시리즈 문학은 사용자 예시 페이지(`빛을 따라서` 시리즈 형태)와 동일하게 **독립된 시리즈 페이지**로 동기화합니다.
   - **시리즈 대표 페이지 구성**:
     - **시리즈 제목**: 시리즈 원 제목 (예: `빛을 따라서`)
     - **속성 (Properties)**: 대표 태그 목록, 총 편수, 수집 차수
   - **본문 하위 회차 구조**:
     - 상위 시리즈 페이지 내부에 회차별(`시리즈 1`, `시리즈 2`, `시리즈 3`...) 서브 페이지 또는 콜아웃/토글 목록 생성.
     - 각 회차 항목 포함 내용: `게시글 제목(ID 포함)`, `게시물 원본 링크`, `회차별 태그`, `첨부 사진 경로 (사진/차수/게시글번호_순번.확장자)`

4. **최종 검증**:
   - 게시물 이름, 원본 링크, 태그(`단편`, `후방주의` 등 포함), 첨부 사진 정보 4가지 정보의 누락 여부를 최종 검증합니다.
