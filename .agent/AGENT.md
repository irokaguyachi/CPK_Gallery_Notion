# 문학 & 노션 통합 관리 에이전트 (.agent)

## 📌 개요
이 에이전트는 **10,000개 단위 분할 크롤링** -> **사진 다운로드** -> **`rules/tag.md` 참조 기반 태그 분류** -> **메모장(1, 2, 3...) 분할 정리** -> **시리즈 묶음 관리** -> **Notion DB 연동**을 전담합니다.

## 🎯 주요 워크플로우
1. **10,000개 단위 크롤링 & 사진 수집**:
   - 게시글 번호 기준 10,000개 단위 수집 (`크롤링/1.md`, `크롤링/2.md` ...).
   - 게시글 내 사진은 **5~10초 완전 로딩 대기** 후 실제 이미지 원본(jpg/png/gif)을 다운로드하여 `사진/1/`, `사진/2/` 하위 폴더에 저장 (`.php` 등 로딩 파일 방지).


2. **`rules/tag.md` 참조 및 태그 분류**:
   - 메모장에 작성하기 전 **반드시 `rules/tag.md` 지침을 열어서 태그 정의를 숙지**한 후 정확한 태그를 할당.
3. **메모장 분할 정리 (`크롤링/1.md`, `크롤링/2.md` ...)**:
   - 파일명과 게시글 번호(ID) 범위 매핑 규칙:
     - `크롤링/1.md`: 게시글 ID **1 ~ 10,000번**
     - `크롤링/2.md`: 게시글 ID **10,001 ~ 20,000번**
     - `크롤링/7.md`: 게시글 ID **60,001 ~ 70,000번** (60,000번대 글은 7.md에 수집)
   - 게시글 번호 범위에 맞는 파일 내에 수집 내용 작성 (게시물 이름, 게시물 링크, 태그, 본문 글자 수, 사진 정보).

   - **시리즈 문학 묶음 정리**:
     - **판별 기준**: 게시글 제목이 같거나 동일 제목 형태인지 여부로 판단.
     - **정리 방식**: 각각의 글로 따로 떼어놓지 않고 하나의 시리즈 묶음 항목 내에 `시리즈 1: [링크/사진]`, `시리즈 2: [링크/사진]` 순서로 한데 묶어서 정리.


4. **Notion 동기화 (`rules/notion-sync.md`)**:
   - 단편 문학 -> 해당 카테고리 Notion DB 항목 등록.
   - 시리즈 문학 -> 사용자 작성 예시 페이지(`빛을 따라서` 시리즈 형태)와 같이 **시리즈 독립 상위 페이지** 생성 후, 내부에 회차별(`시리즈 1`, `시리즈 2`, `시리즈 3`...) 항목을 포함시켜 Notion DB 업데이트.

5. **크롤링 현황 기록 (`CurrentStats.md`)**:
   - 작업 완료 시 **`CurrentStats.md`**에 마지막 크롤링한 페이지 번호, 게시글 ID, 작업 완료 일시, **총 수집 문학 건수, 총 수집 글자 수(및 텍스트 용량), 총 수집 사진 수 및 총 사진 용량**을 자동 기록.
